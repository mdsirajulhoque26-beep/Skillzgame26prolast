# V23 — Settings Save + Flexible Multiplayer

- Admin Settings Save no longer blocks on an empty WhatsApp field.
- Multiplayer rows are configurable for any unique player count from 3 to 1000.
- Add/remove Player Count controls are available in Admin Settings.
- Each row supports Entry Fee, number of prize winners, rank prizes, Active, and Home visibility.
- Server accepts any configured multiplayer player count from 3 to 1000 instead of only 3/5/7/10.
- After a successful Settings save, the app returns to Home.
- Existing Universal Match History remains included.
