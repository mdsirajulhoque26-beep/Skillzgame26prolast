# Universal Match History – V21

Home > History is now a separate `history` tab.

Changes:
- Home History button opens the new standalone HistoryScreen.
- History no longer routes through BlockPuzzleDuel / Pro Match lobby.
- History loads the user's combined match feed and deduplicates records.
- Completed results are shown with filters: All, Pro Match, Tournament, Other.
- Shows result, opponent, scores, entry fee, prize and date.
- Pending matches remain separate from completed History.
