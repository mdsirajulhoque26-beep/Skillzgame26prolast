# V39 Live Support Chat

Player Profile → Admin Support now opens an in-app support chat. Players can send messages, receive admin replies, and close/reopen a conversation. Admin Panel has a Support Chat tab with unread counts, conversation list, replies, and close/re-open controls.

Support chats are persisted in the existing database under `supportChats`; no existing match/history/dispute/balance records are changed by this feature.
